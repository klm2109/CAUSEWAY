What does Paper2Agent contribute?

Paper summary • preprint v2, October 2025

  • Connect a paper, its code and data to a conversational assistant.
  • Expose reusable functions through Model Context Protocol (MCP).
  • Test functions against reference examples before exposing them.
Speaker notes

MCP is a shared interface through which an assistant can discover and call functions. The conversational assistant and scientific function have different roles.

How the paper builds an agent

Paper summary • the reusable workflow

  • Locate code → configure environment → inspect tutorials.
  • Execute reference examples → extract tools → validate results.
  • Tools perform work; resources provide context; prompts guide workflows.
  • Connect the resulting server to an LLM-based assistant.
Speaker notes

A language model handles the conversation. Scientific functions handle calculations. This separation is the architectural idea we can apply to CAUSEWAY.

Evidence and limits

Paper summary • what the demonstrations establish

  • Case studies: AlphaGenome, TISSUE and Scanpy.
  • AlphaGenome: 15/15 tutorial queries and 15/15 novel queries correct in the reported benchmark.
  • These are selected computational benchmarks, not clinical validation.
  • Incomplete source code can prevent reliable tool creation.
Speaker notes

Treat these results as evidence for the demonstrated tasks, not a guarantee for every future scientific agent. The preprint and journal version differ; the figures on this slide refer specifically to preprint v2.

Apply the idea to CAUSEWAY

Our proposal • not an experiment reported in Paper2Agent

  • Researcher asks a question about TACO.
  • Assistant selects a documented tool and checks its inputs.
  • Tool returns structured evidence with source links and status.
  • Assistant explains the result and what remains unknown.
Speaker notes

Example: ask what data TACO requires. The assistant calls the TACO evidence tool, then explains the returned requirements. A tool response is like a labelled envelope: it contains the answer, its source and whether an analysis actually ran.

First TACO agent: a small useful start

Our implementation scope

  • Retrieve TACO purpose, input requirements and limitations.
  • Check whether a proposed data manifest is complete.
  • Expose tools, a reference resource and a workflow prompt via MCP.
  • Prediction execution remains unavailable until the upstream pipeline is reproduced.
Speaker notes

A manifest describes a dataset without sending its measurements. Our first version checks this description. It does not establish that the data are biologically suitable. An MCP host supplies the language model; the website exposes the same evidence tools without claiming to be an LLM chat.

How can methods be combined?

Our experiment planning tool

  • Select methods and inspect the proposed combination.
  • Check shared gene identifiers, cohort definitions and data requirements.
  • Label published pipelines separately from proposed combinations.
  • Compare methods with task-specific metrics and independent validation.
Speaker notes

A combination is a research recipe, not a result. Selecting ingredients does not prove that they work together. Methods may use incompatible tissues or cohorts, and reusing the same dataset can make an apparent comparison overly optimistic.
